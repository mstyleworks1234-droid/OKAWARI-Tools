# QuickShot 1.0.1

## 日本語

Windows 10/11（64ビット）向けの無料アプリです。マウスで選んだ範囲をクリップボードへコピーします。会員登録、通信、アプリ内広告はありません。

- 1.0.0 の EXE は置き換えていません。

## English

Free app for 64-bit Windows 10/11. Select a region with the mouse and it is copied to the clipboard. No account, no network access, and no in-app ads.

### This version

- The resident button stays inside the usable screen and no longer slides under the taskbar.
- The 1.0.0 EXE is unchanged.
