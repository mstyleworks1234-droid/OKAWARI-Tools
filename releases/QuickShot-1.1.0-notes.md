# QuickShot 1.1.0

## 追加

- ボタンの中段、または右クリックから、表示中のモニター全部を1枚の PNG で保存する。複数モニターのときは台数を表示する。
- ボタンの下段、または右クリックから、Chrome / Edge の表示中ページを上から下まで1枚の PNG で保存する。
- 範囲指定の撮影は、これまでどおりクリップボードへコピーする。

## ページ全体の条件

- 初回だけ、同梱の拡張機能を Chrome または Edge に読み込む。
- QuickShot はブラウザを終了も再起動もしない。
- 対象は表示中の http / https ページ。chrome:// のページは撮影できない。
- 固定ヘッダーは撮影中だけ隠し、終了後に戻す。スクロール位置も戻す。
- 非常に長いページは上から 20000 CSS ピクセルで打ち切る。
- 外部のウェブページから撮影は開始できない。接続は 127.0.0.1 と拡張機能専用トークンだけを使う。

## 保存先

`%USERPROFILE%\Pictures\QuickShot`

1.0.1 の EXE は置き換えない。
