# QuickShot 1.1.16

Windows 10 / 11（64ビット）向けの無料アプリです。コード署名はありません。

- 範囲指定、画面全体、ページ全体、ChatGPTの会話をPNGで保存できます。
- ページ全体と会話の撮影には、同梱のChrome / Edge拡張機能が必要です。拡張機能はChromeウェブストアでは公開していません。
- 長いページは複数のPNGに分割されます。
- ChatGPTの会話撮影では、画面下の入力欄が分割画像に写り込まないようにしました。
- 日本語と英語の文字認識、簡単な画像編集、撮影履歴を使えます。
