QuickShot

無料 Windows

画面の範囲をマウスで選ぶと、その画像をクリップボードへコピーします。保存や編集の画面は出ません。

主な特徴

  • マウス操作だけで範囲を撮影し、画像としてコピーします。
  • 撮影後は自動で元の画面に戻ります。編集画面はありません。
  • Escキーで範囲選択をキャンセルできます。
  • 複数モニターと、表示の拡大率に対応します。
  • 常駐ボタンはドラッグで移動でき、位置を保存します。
  • 右クリックで終了します。撮影の瞬間はボタンを隠します。

使い方

  1. QuickShotを起動します。
  2. 画面端のカメラボタンをクリックします。
  3. 撮りたい範囲をマウスでドラッグします。
  4. マウスを離すと、その範囲がコピーされます。
  5. ChatGPT、LINE、Discordなどへ Ctrl+V で貼り付けます。

起動方法

  1. ダウンロードしたEXEを、任意のフォルダに保存します。
  2. EXEをダブルクリックして起動します。
  3. 「WindowsによってPCが保護されました」と出た場合は、「詳細情報」を開いて「実行」を選びます。この初期版はコード署名をしていないため、表示されることがあります。
  4. 管理者権限や、別のインストール作業は不要です。

終了と削除

  1. カメラボタンを右クリックし、「終了」を選びます。
  2. 保存したEXEを削除します。
  3. ボタン位置などの設定も消すときは、%APPDATA%\OKAWARI\QuickShot フォルダを削除します。スタートアップやレジストリへの登録は行いません。

セキュリティ上の注意

  • スクリーンショットはファイルに保存せず、パソコンのメモリとクリップボードだけで扱います。
  • 開発者のサーバーへ画像や利用状況を送りません。
  • 自動更新機能はありません。アプリが自分で別のプログラムを取りに行くことはありません。
  • 公開されているSHA-256と、手元のファイルの値が一致することを確認してください。
  • 入手元のわからないコピーは実行しないでください。

よくある質問

画像はどこに保存されますか？

ファイルには保存しません。クリップボードにだけ入ります。その後で別の内容をコピーすると、置き換わります。

料金はかかりますか？

QuickShotの利用に料金はありません。アカウントも不要です。アプリの中に広告は出ません。

どのWindowsで使えますか？

Windows 10およびWindows 11の64ビットを対象にしています。

ボタンがスクリーンショットに写りますか？

撮影の直前にボタンを隠し、コピーが終わってから戻します。

どうやって終了しますか？

カメラボタンを右クリックして「終了」を選びます。

2回起動するとどうなりますか？

2つ目は起動しません。すでに起動していることを知らせる画面を表示します。

再起動したあとは自動で立ち上がりますか？

自動起動はしません。使うときにEXEを開いてください。ボタンの位置はパソコン内に保存されています。
